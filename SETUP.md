# Publishing this site on GitHub Pages

## Step 1 — Set your repository URL

Open `build.py` and edit line 15:

```python
REPO_URL = "https://github.com/YOUR-USERNAME/YOUR-REPO"
```

This one value fills in every "link to the code" and "link to the data" reference across
the site — the assignment requires those links, and they are currently placeholders.

## Step 2 — Rebuild the pages

```bash
pip install matplotlib numpy
python make_figures.py      # writes assets/figures/
python build.py             # writes the 11 .html files
```

Open `index.html` in a browser to check it before pushing.

## Step 3 — Copy into your repository

Copy everything except `build.py` and `make_figures.py` into the root of your repo (you
can keep those two in the repo as well — the assignment asks you to link to your code, so
having them visible is a plus):

```
your-repo/
├── index.html
├── dataprep_eda.html
├── clustering.html
├── pca.html
├── naivebayes.html
├── dectrees.html
├── svms.html
├── regression.html
├── nn.html
├── conclusions.html
├── about.html
├── assets/
│   ├── style.css
│   └── figures/
├── build.py
└── make_figures.py
```

`index.html` must be at the repository root, not inside a subfolder — that is the file
GitHub Pages serves as your homepage.

## Step 4 — Push

```bash
git add .
git commit -m "Module 1: project website with all tabs, introduction, and EDA"
git push
```

## Step 5 — Turn on GitHub Pages

1. Go to your repository on github.com
2. **Settings** → **Pages** (left sidebar)
3. Under "Build and deployment", set **Source** to **Deploy from a branch**
4. Set **Branch** to `main` and the folder to `/ (root)`
5. Click **Save**

Wait one to two minutes. The page will then show your URL:

```
https://YOUR-USERNAME.github.io/YOUR-REPO/
```

That URL is what you submit.

## Step 6 — Check it before submitting

- Open the URL in a private/incognito window (this catches files you forgot to commit —
  they'll work locally but 404 on the live site).
- Click every tab in the navigation bar.
- Confirm images load on the Introduction and DataPrep_EDA pages.
- Confirm the "link to the code" and "link to the data" links go somewhere real.

## Step 7 — Submit

The assignment asks for the URL placed in a `.docx` file, named with your name and
"Project A1". Nothing else goes in the document.

# What still needs your data

Every figure currently shows a labelled placeholder. To replace them with real ones:

```bash
# 1. run the collection pipeline (from the bandsintown-thesis project)
python src/seeds.py --range this-week
python src/crawl.py
python src/normalize.py

# 2. regenerate the figures, pointing at your database
python make_figures.py ~/thesis/bandsintown-thesis/data/bandsintown.sqlite

# 3. commit and push
```

`make_figures.py` produces real figures when the database has data and placeholders when
it doesn't, so the site is never broken at any point in between.

You also need to commit the actual data files somewhere under `data/` in the repo, because
the assignment requires links to both the raw and the cleaned data. A representative
sample is fine if the full dataset is too large for GitHub — just say on the page that it
is a sample.
